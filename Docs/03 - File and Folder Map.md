# Project Crown: Europa Ascendant — File & Folder Map

Two trees: the **mod itself** (goes in `Mod Build/`) and the **project workspace** around it. Names prefixed `crown_` throughout so overrides vs. additions are always obvious.

```

│   └── project_crown/             # The actual mod (tree below)

│   ├── classify_provinces.py      # Flattened-region dev classes — Americas/Africa/Oceania only (1/1/1, 1/2/1, 1/2/2)
│   ├── emit_province_history.py   # Writes history/provinces overrides
│   ├── native_lookup_gen.py       # Province → native culture/religion scripted effects
│   ├── colonial_region_validator.py # Ocean access + clean borders + no TC overlap
│   └── home_regions/              # Source-of-truth claim lists (UK, France, Spain, Germany modern borders; Alsace-Lorraine contested zone)

└── Test Notes/                    # Spike verdicts + observer-run logs
```

## Conventions

- **Generated files are never hand-edited.** `history/provinces/` and `crown_native_lookup.txt` come from `Tooling/`; fixes go into the tooling inputs (classifier rules, override lists), then regenerate.
- **Full overrides are called out** (adjacencies, colonial regions) — these are the files most likely to break on game patches; keep a diff-against-vanilla note in Test Notes per patch.
- **One system per event file**, ids namespaced (`crown_colonial.1`, `crown_backing.1`, …).
- Exact filenames inside `common/` that shadow vanilla files (e.g., ideas) must match vanilla names where override-by-name is required — resolved during Phase 0 skeleton work.
